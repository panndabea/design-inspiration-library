# Spatial / Physical Data Room

## Description
Data is experienced in physical or immersive space – installations, operations rooms, XR.

## UX goal
Shared discussion and presence of otherwise invisible data.

## Visual characteristics
Large-scale landscapes, ambient peripheral displays.

## Interaction behavior
Bodily movement, shared viewing, low active interaction.

## Suitable project types
- exhibitions
- workshops
- operations rooms

## Unsuitable project types
- everyday web/desktop products
- frequent updates (report – expensive
- slow
- hard to update; XR hardware/usability immature)

## Implementation considerations
Treat as a special-purpose channel fed by the same semantic model.

## Accessibility and performance
Physical accessibility and a non-immersive equivalent are mandatory.

## Anti-patterns and risks
- 3D because it looks futuristic
