# Narrate, then Explore

## Description
A guided default view tells the main story; clearly marked branches open free exploration and alternative views (chart, map, table).

## UX goal
Balance author guidance and reader freedom.

## Visual characteristics
Narrative layer on top; exploration layer with consistent controls; sources always visible.

## Interaction behavior
"Explore this" entry points from narrative steps; view switching; download data.

## Suitable project types
- public data portals
- explainers
- analytics products

## Unsuitable project types
- pure tools with expert users who know what they look for

## Implementation considerations
Same data model and state URL for narrative and exploration modes.

## Accessibility and performance
Table view doubles as accessible alternative.

## Anti-patterns and risks
- only story or only sandbox (manifesto anti-pattern)
