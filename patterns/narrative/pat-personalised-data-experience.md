# Personalised Data Experience

## Description
The user's own context (location, role, data, drawing) becomes the entry point to the story.

## UX goal
Make abstract or global topics personally relevant.

## Visual characteristics
Story template filled with the user's context; comparison to the whole.

## Interaction behavior
Choose or provide own context at the start; continue to the general picture.

## Suitable project types
- global trend explainers
- personal reports
- role-based briefings
- onboarding

## Unsuitable project types
- contexts where personal data cannot be handled responsibly

## Implementation considerations
Design the default (non-personalised) path first; personalisation as enrichment.

## Accessibility and performance
Consent and privacy notices; no tracking without consent.

## Anti-patterns and risks
- demanding personal data before showing value
