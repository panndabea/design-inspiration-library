# Annotated Timeline

## Description
Data, events and decisions are placed on a shared time axis with editorial annotations.

## UX goal
Support discussion of causes and turning points over time.

## Visual characteristics
Horizontal or vertical time axis, event markers, annotation layer distinct from data.

## Interaction behavior
Scrub or zoom in time, expand events, filter event types.

## Suitable project types
- history explainers
- project journeys
- strategy reviews
- technology trend histories

## Unsuitable project types
- data without meaningful temporal order

## Implementation considerations
Model events, measurements and decisions as separate typed layers.

## Accessibility and performance
Chronological list equivalent; keyboard navigation between events.

## Anti-patterns and risks
- implying causation from co-occurrence (report risk)
