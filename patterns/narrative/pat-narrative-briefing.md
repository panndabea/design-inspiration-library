# Narrative Briefing

## Description
A small number of prioritised statements ("What? Why? What now?") in a logical sequence, each backed by evidence that can be expanded.

## UX goal
Fast orientation for decision makers.

## Visual characteristics
Headline statements with compact evidence visuals; strong typographic hierarchy instead of a KPI grid.

## Interaction behavior
Expand evidence, jump to exploration, mark as read/acted upon.

## Suitable project types
- management start pages
- portfolio overviews
- periodic reviews

## Unsuitable project types
- ad-hoc analysis by experts (needs exploration branches)

## Implementation considerations
Generate or author statements from a ranked list of changes; each statement links to its data.

## Accessibility and performance
Statement-first structure is screen-reader friendly by default.

## Anti-patterns and risks
- 25 equally weighted KPI cards (manifesto anti-pattern)
- narrative bias without evidence
