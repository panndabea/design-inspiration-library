# Playable Story

## Description
A narrative in which the user plays a role or a game; the model is revealed after the user has experienced its consequences.

## UX goal
Create emotional engagement and memorable understanding of systems and dilemmas.

## Visual characteristics
Illustrated characters or toy-like elements, chaptered progression.

## Interaction behavior
Choices and rounds of play followed by reflection and explanation.

## Suitable project types
- social and behavioural topics
- ethics
- public engagement
- learning games

## Unsuitable project types
- professional tools
- topics where gamification trivialises harm

## Implementation considerations
Script the narrative arc first (experience → surprise → explanation → free play).

## Accessibility and performance
Turn-based interaction is preferable to time pressure; provide text alternative for each chapter.

## Anti-patterns and risks
- points and badges unrelated to the learning goal
