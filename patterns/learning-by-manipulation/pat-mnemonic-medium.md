# Mnemonic Medium

## Description
Retrieval-practice questions are embedded in the content and scheduled for later review.

## UX goal
Turn one-off reading into durable knowledge.

## Visual characteristics
Unobtrusive review cards between sections.

## Interaction behavior
Answer, reveal, self-grade; later review sessions.

## Suitable project types
- courses
- onboarding
- certification preparation

## Unsuitable project types
- casual one-time stories
- anonymous public sites without persistence

## Implementation considerations
Requires user identity or local storage for the review schedule.

## Accessibility and performance
Cards must be fully keyboard and screen-reader operable.

## Anti-patterns and risks
- quizzes that test trivia instead of the key ideas
