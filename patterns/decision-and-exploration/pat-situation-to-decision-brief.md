# Situation-to-Decision Brief

## Description
Real-time situation data is analysed and composed into a contextual report that ends in concrete options for action.

## UX goal
Interfaces end in a decision, not only in observation.

## Visual characteristics
Situation context (map/timeline) + summary + decision options with consequences.

## Interaction behavior
Choose option, assign, record decision and rationale.

## Suitable project types
- operations
- crisis response
- executive and portfolio decisions

## Unsuitable project types
- purely educational content

## Implementation considerations
Model decisions as first-class objects linked to evidence.

## Accessibility and performance
Decision options as standard form controls.

## Anti-patterns and risks
- observation without next option (manifesto anti-pattern)
