# Interaction Design Principles

Tags: **[R18]**, **[R19]**, **[G]** as in `visual-design.md`.

1. **Interaction must reveal meaning.** If an interaction does not change what the user understands, remove it. [R18 Setosa "interactive = intuitive", "substance > information"]
2. **One mechanism, one primary control.** The best works pick a single mechanism and make it manipulable. [R18]
3. **Choose the medium per idea** – text for abstract ideas, graphics for relationships, animation for temporal processes, interactivity for systems and models (Nicky Case, as summarised in Report 18). [R18]
4. **Simple to complex.** Stage progression so each step adds one variable. [R18 Ciechanowski, Mathigon]
5. **Narrate, then let me explore.** Guided default, explicit exploration branches. [R19, Segel & Heer]
6. **Manipulation for discovery, filters for precision.** [R19]
7. **Preserve agency.** Suggestions are editable, never silently applied. [R19 Pluto]
8. **Chat is an entry point, not the whole UI.** Conversations create persistent structured objects. [R19]
9. **End in a decision.** Information interfaces should lead to a next action. [R19 "Decision before dashboard"]
10. **Meaningful default state.** Pages must communicate the key idea before any interaction. [G]
11. **Motion explains change.** Use transitions that preserve object identity; never animate for decoration. [R18 R2D3] [G]
