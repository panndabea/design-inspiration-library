# Visual Design Principles

Tags: **[R18]** = derived from Report 18, **[R19]** = derived from Report 19, **[G]** = general guidance added by the library (not a research finding).

1. **Form carries meaning.** Every visual property (position, size, colour, motion) encodes something; remove what doesn't. [R19 "Use visual grammar, not visual decoration"]
2. **Pick a design language deliberately.** Report 18 identifies five recurring languages – choose one per project and state why:
   - *editorial-minimalist* (MLU-Explain, Distill, Seeing Theory, Setosa): white space, restricted palettes, visualisations inside the text flow.
   - *technical-spatial* (Ciechanowski, Immersive Math, Brain Flux): WebGL/Canvas figures forming physical or mathematical spaces.
   - *playful-systemic* (Nicky Case, Complexity Explorables, Mathigon): learning by experiment rather than linear reading.
   - *data-editorial* (The Pudding, Glocal Climate Change): scrollytelling, typographic dramaturgy, journalistic narrative.
   - *research-native* (Distill, PAIR, Polo Club): the interactive medium is part of the scientific method. [R18]
3. **Typography is the primary hierarchy.** Statements and headlines lead; numbers support. [R19 "Lead with meaning"] [R18 Ciechanowski typography]
4. **Restricted palette, semantic colour.** Reserve saturated colour for the thing that changes or matters; keep a consistent colour ↔ concept mapping across text and figures. [R18 editorial-minimalist] [G]
5. **Space only when space means something.** Use maps, landscapes or 3D only when position encodes meaning. [R19]
6. **One dominant figure per idea.** Avoid grids of equal-weight cards. [R18 "one mechanism"] [R19 KPI-card anti-pattern]
7. **Show uncertainty visually** (bands, ensembles, hatched areas), never as false precision. [R19]
8. **Distinguish fact, model and hypothesis visually** with consistent markers. [R19]
9. **Consistency over novelty inside a product.** Adaptive UIs must keep semantics and layout stable. [R19 "Keep semantics stable"]
